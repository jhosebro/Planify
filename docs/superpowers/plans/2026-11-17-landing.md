# Landing web — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A web-only landing page, shown to visitors who aren't signed in, that turns them into registered users.

**Architecture:** New `LandingScreen` inside `AuthStack`. It is the initial route on web only; native keeps `Login`. The page is one scrollable column built with RN primitives and the existing theme hooks.

**Tech Stack:** Expo SDK 57, react-native-web, React Navigation native-stack, `AppIcon` (lucide), `useThemeColors`, `useResponsiveLayout`.

**Spec:** `docs/superpowers/specs/2026-11-17-landing-design.md`

## Global Constraints
- The landing renders only when `Platform.OS === 'web'` and there is no session. Native apps never show it.
- All copy is in Spanish.
- Colors come from `useThemeColors()` (light + dark). No hardcoded hex values except white text on primary.
- `PLAY_STORE_URL: string | null = null`. When null, show a non-clickable "Próximamente en Google Play" badge. When set, show a "Descargar en Google Play" link that opens the URL.
- No real user data in the hero mockup; use hardcoded sample figures.
- No new dependencies.

## Review Focus
- Narrow viewport (≤ 400px): hero stacks vertically, nothing overflows horizontally. Verify via Playwright at 390px.
- Dark mode: text is readable on every section. Verify via `emulate_media` dark.
- A signed-in user who opens `/` must land in the app, not on the landing. Already guaranteed by `AppNavigator` choosing Main; verify once.
- Browser back from Register/Login returns to the landing. Expected with the native-stack history on web; verify once.
- Tab title reads "Planify — Finanzas personales" on the landing (set the screen `title` option).
